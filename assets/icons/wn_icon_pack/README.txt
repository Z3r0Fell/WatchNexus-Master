WatchNexus Extension Icon Pack (cross-platform)

Included per extension:
- PNG icons: 16, 24, 32, 48, 64, 96, 128, 256, 512, 1024
- Windows ICO: multi-size bundled icon (.ico)
- macOS ICNS: application icon (.icns)
- macOS AppIcon.appiconset folder (Xcode-friendly)
- Naming uses: watchnexus_<extension-without-dot>_<size>.png

Platform usage:
- Windows: use .ico for file associations / installer resources
- macOS: use .icns or AppIcon.appiconset
- Linux desktop: use PNG (128/256/512)
- Docker/Unraid: use PNG (usually 128/256/512 or 1024 for app templates)

Source inspiration:
- Based on the WatchNexus application logo (provided image), adapted into per-extension icon variants.
