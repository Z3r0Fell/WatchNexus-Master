# WatchNexus Container-Specific Banner Pack

This pack contains branded wide-format banners generated for each WatchNexus file/extension type,
using the main WatchNexus logo as inspiration.

## Included formats (per extension)
- docker_unraid_banner (1600x600) — wide app listing / repo header banner
- docker_hub_social (1200x630) — social share / Docker Hub social preview
- dashboard_banner (1024x512) — Homarr/Homepage/Heimdall-style dashboard cards (2:1)
- stack_preview (1280x720) — 16:9 preview image / docs / release notes

## Extensions covered
- .wn  (Module)
- .wnf (Framework)
- .wnc (Config)
- .wnd (Data)
- .wnp (Plugin)
- .wnt (Theme)
- suite (generic container branding)

Tip: If you want next pass variants, request:
- dark-mode / light-mode
- monochrome
- transparent text-free header backgrounds
- per-service container banners (e.g., API, WebUI, DB, Worker)
