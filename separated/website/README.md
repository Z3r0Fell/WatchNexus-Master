# WatchNexus Website

Static marketing/documentation website for WatchNexus.

## Pages

- `index.html` - Home/landing page
- `features.html` - Feature overview
- `downloads.html` - Download links
- `documentation.html` - User docs
- `support.html` - Support/FAQ
- `troubleshooting.html` - Common issues

## Hosting

This is a static site - deploy to any web host:
- GitHub Pages
- Netlify
- Vercel
- Any web server

## Development

Simply open HTML files in a browser or use a local server:

```bash
python -m http.server 8080
```
