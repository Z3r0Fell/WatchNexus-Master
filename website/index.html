Quick start

One command.
Your media server.

WatchNexus Standard ships as a Docker image. Point it at your media, open port 8001, and the setup wizard does the rest.

  1. Run the containerSwap /path/to/media for your library folder.
  2. Open http://your-server:8001Create your admin account in the setup wizard.
  3. Add a libraryPoint it at /data/media and grab some popcorn.
Full install guide 
$ docker run -d \
    --name watchnexus \
    -p 8001:8001 \
    -v watchnexus-data:/app/data \
    -v /path/to/media:/data/media \
    -e WATCHNEXUS_TIER=standard \
    -e TZ=America/Toronto \
    --restart unless-stopped \
    watchnexus/watchnexus:latest-standard
services:
  watchnexus:
    image: watchnexus/watchnexus:latest-standard
    container_name: watchnexus
    ports:
      - "8001:8001"
    volumes:
      - watchnexus-data:/app/data
      - /path/to/media:/data/media
    environment:
      - WATCHNEXUS_TIER=standard
      - TZ=America/Toronto
    restart: unless-stopped
