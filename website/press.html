About WatchNexus

WatchNexus is a self-hosted, unified media pipeline that combines the best of media servers like Jellyfin with the automation power of the *arr ecosystem — all in a single Docker container.

Built with C#/.NET 10 and React 18, it gives users complete control over their media libraries without relying on third-party cloud services. 73 modules, zero external dependencies, one binary.
