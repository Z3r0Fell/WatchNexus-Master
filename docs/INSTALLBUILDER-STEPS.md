# InstallBuilder Steps

This document provides step-by-step instructions for building WatchNexus installers using InstallBuilder.

## Prerequisites

- InstallBuilder 26 or later
- WatchNexus staging directory prepared via `prepare-installers.sh`

## Steps

1. Open the InstallBuilder project file from the staging directory
2. Select the target platform (Windows, Linux, macOS)
3. Choose the tier (Standard, Pro, Ultra)
4. Build the installer
5. Sign the installer with your code signing certificate

For detailed instructions, see the InstallBuilder documentation.
