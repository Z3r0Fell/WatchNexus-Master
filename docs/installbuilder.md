# InstallBuilder Reference

This is the full reference manual for WatchNexus InstallBuilder configurations.

## Project Structure

- `installer.xml` — Main InstallBuilder project file
- `resources/` — Icons, license files, and other assets
- `scripts/` — Pre-install, post-install, and uninstall scripts
